## Completion Notes

- Added Google OAuth connect, callback, refresh, revoke, and disconnect primitives with PKCE and encrypted state validation.
- Requested only calendar-list read access and calendar-event write access, with offline consent for refresh tokens.
- Added encrypted server-side token persistence and a migration that prevents browser roles from selecting token ciphertext.
- Added focused provider and route tests covering state ownership/expiry, token grants, secure cookies, encrypted persistence, and disconnect behavior.
- Live OAuth still requires `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_OAUTH_REDIRECT_URI`, and a base64-encoded 32-byte `OAUTH_TOKEN_ENCRYPTION_KEY` in the runtime environment.
