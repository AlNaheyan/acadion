# Wave 4, Ticket 4.1 — Course Tables / Models

Wave: Database Persistence

Status: Complete

## Goal

Store user-owned imported course metadata without changing the existing catalog course model.

## Implemented

- Added the first versioned Supabase migration.
- Added a dedicated public.imported_courses table separate from public.courses.
- Added UUID identity, Clerk user ownership, nullable extracted metadata, extraction status, warnings, and timestamps.
- Added status and JSON-array constraints, a user index, and an updated-at trigger.
- Enabled RLS with Clerk JWT subject read/delete policies.
- Added typed row/insert models and a canonical extraction-to-row mapper.
- Preserved null extracted values without fallback invention.

## Tests

- Complete and null-safe course mapping.
- Migration table separation, index, constraints, RLS, owner policy, and warning storage.

## Result

Complete. Three focused persistence tests pass with typecheck and lint.
