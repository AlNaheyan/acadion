# Wave 4, Ticket 4.4 — Syllabus Upload Record

Wave: Database Persistence

Status: Complete

## Goal

Track safe upload metadata and extraction lifecycle without retaining raw syllabus text.

## Implemented

- Added a versioned syllabus_uploads migration.
- Stored Clerk ownership, optional course relationship, file name/size/type, optional storage key, and SHA-256 checksum.
- Constrained PDF MIME type, the 10 MB upload limit, and checksum format.
- Added pending, extracting, success, and failed lifecycle states.
- Required successful uploads to reference a course and limited error codes to failures.
- Added lookup indexes, timestamps, update trigger, RLS, and owner read/delete policies.
- Added typed upload records and a null-safe pending-state mapper.
- Deliberately excluded raw extracted syllabus text.

## Tests

- Complete and storage-free upload metadata mapping.
- Migration limits, lifecycle, successful-course relationship, RLS, and raw-text exclusion.

## Result

Complete. Twelve relevant persistence tests pass with typecheck and lint.
