# Wave 4, Ticket 4.5 — Import Transaction

Wave: Database Persistence

Status: Complete

## Goal

Prevent partially persisted syllabus imports.

## Implemented

- Added one security-invoker PostgreSQL import_syllabus function.
- Enforced caller ownership unless invoked through the service role.
- Inserted the imported course, exploded weekday meetings, assessments, relative rules, and successful upload record in one function transaction.
- Relied on PostgreSQL exception semantics so any failed statement rolls back the complete import.
- Restricted function execution to authenticated and service roles.
- Added a TypeScript RPC adapter that submits the complete canonical extraction in one call.
- Added stable safe persistence errors without leaking database details.
- Rejected missing course IDs even when a transport reports no error.

## Tests

- Complete single-RPC argument mapping and returned course ID.
- Safe database failure mapping and invalid empty responses.
- Migration authorization, all entity inserts, privilege restriction, and absence of exception swallowing.

## Result

Complete. Eight focused transaction/migration tests pass with typecheck and lint. Applying migrations to a live Supabase project remains a deployment operation.
