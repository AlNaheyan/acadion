# Wave 1, Ticket 1.2 — Add Schema Validation

Wave: Domain Models and Schema

Status: Complete

## Goal

Prevent malformed extraction output from reaching persistence or UI.

## Implemented

- Added validateCourseExtraction with a stable success/failure result.
- Converted Zod failures into deterministic path and message records.
- Rejected impossible ISO calendar dates.
- Enforced forward meeting date/time ranges.
- Required due dates for due times and event dates for event times.
- Required confirmed assessments to contain a calendar date.
- Prevented unconfirmed assessments from carrying normalized calendar dates.
- Enforced unique assessment IDs.
- Rejected warnings that reference unknown assessments.

## Tests

- Valid canonical data and defaults.
- Impossible dates and backward ranges.
- Invalid assessment date/time relationships.
- Duplicate IDs and invalid warning references.
- Valid TBD assessments without invented dates.

## Result

Complete. Eight focused validation tests pass; thirteen schema and validation tests pass together.
