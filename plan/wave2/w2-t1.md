# Wave 2, Ticket 2.1 — PDF Upload Validation

Wave: PDF Upload and Text Extraction

Status: Complete

## Goal

Reject unsupported uploads before invoking a PDF parser.

## Implemented

- Added a server-safe upload interface compatible with web `File` objects.
- Enforced a configurable 10 MB default size limit.
- Rejected empty files, wrong MIME types, and non-PDF extensions.
- Verified the `%PDF-` binary signature to reject spoofed metadata.
- Added stable error codes and user-safe messages for every failure class.
- Exported PDF upload validation through the syllabus module.

## Tests

- Valid PDF and uppercase extension.
- Empty and oversized uploads.
- Wrong MIME type and extension.
- Spoofed PDF metadata/signature.
- Caller-defined size limits.

## Result

Complete. Eight focused upload-validation tests pass with typecheck and lint.
