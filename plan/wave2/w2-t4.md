# Wave 2, Ticket 2.4 — Table-Friendly Text Handling

Wave: PDF Upload and Text Extraction

Status: Complete

## Goal

Preserve useful row and column relationships in ordinary text-based syllabus tables.

## Implemented

- Reconstructed rows by grouping positioned PDF text within a configurable vertical tolerance.
- Sorted rows top-to-bottom and cells left-to-right regardless of parser item order.
- Preserved meaningful column gaps with an explicit pipe separator.
- Joined nearby fragments as ordinary prose rather than false table cells.
- Added normalized line-preserving fallback behavior when position data is unavailable.
- Added explicit one-based page markers, including markers for empty pages.
- Kept the formatter deterministic and text-only without OCR or semantic guessing.

## Tests

- Shuffled two-column assessment tables.
- Nearby prose fragments.
- Minor baseline coordinate differences.
- Fallback line normalization.
- Multi-page boundaries and empty-page fidelity.

## Result

Complete. Six focused formatting tests pass with typecheck and lint.
