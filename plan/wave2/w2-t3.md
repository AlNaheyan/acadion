# Wave 2, Ticket 2.3 — Text Quality Validation

Wave: PDF Upload and Text Extraction

Status: Complete

## Goal

Reject empty, insufficient, or corrupted text extraction before LLM processing.

## Implemented

- Added privacy-safe page, character, word, and readable-character metrics.
- Added configurable minimum character, word, and readable-ratio thresholds.
- Identified empty/image-only files as unsupported scanned documents.
- Identified extremely short extraction separately from corrupted extraction.
- Added stable error codes and user-safe messages without logging raw text.

## Tests

- Normal multi-page syllabus text and returned metrics.
- Empty page lists and whitespace-only pages.
- Extremely short extraction.
- Corrupted/unreadable character-heavy extraction.
- Explicit fixture thresholds.

## Result

Complete. Six focused quality tests pass with typecheck and lint.
