# Wave 2, Ticket 2.2 — PDF Text Extraction

Wave: PDF Upload and Text Extraction

Status: Complete

## Goal

Extract machine-readable syllabus text page-by-page while retaining layout metadata.

## Implemented

- Added PDF.js as the server-side parsing engine.
- Added ordered one-based page extraction from `ArrayBuffer` or `Uint8Array` input.
- Returned stable `{ page, text, items }` records for every page.
- Preserved item text, x/y coordinates, width, height, and explicit line endings.
- Isolated PDF.js behind `extractPdfText` so parser details do not leak into later services.
- Ensured parser resources are destroyed after success or failure.
- Added a stable `PdfExtractionError` that does not expose parser internals to users.

## Tests

- Real synthetic multi-page PDF extraction and page order.
- Text and coordinate preservation.
- `ArrayBuffer` input.
- Malformed PDF failure mapping.

## Result

Complete. Three focused extraction tests pass with typecheck and lint.
